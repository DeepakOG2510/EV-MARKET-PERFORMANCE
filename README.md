# EV Market Performance & Insights Dashboard 🚗⚡

An interactive data visualization and analytics dashboard built to analyze Electric Vehicle (EV) market trends, adoption rates, manufacturer performances, and future market projections.

---

## 📊 Overview
This project provides deep insights into the rapidly evolving Electric Vehicle ecosystem. Using Tableau, this dashboard aggregates key metrics to help stakeholders, analysts, and enthusiasts understand geographical adoption trends, infrastructure growth, and leading automotive brands in the EV space.

---

## 🚀 Key Features & Insights
* **Market Adoption Trends:** Tracks the exponential growth of EV registrations over time.
* **Manufacturer Performance:** Compares market share and sales volume among leading EV producers.
* **Geographical Distribution:** Highlights top-performing regions and charging infrastructure density.
* **Interactive Filtering:** Allows users to filter data dynamically by year, region, vehicle type, and manufacturer.

---

## 🛠️ Tools & Technologies
* **Data Visualization:** Tableau (`.twbx`)
* **Documentation:** Markdown
